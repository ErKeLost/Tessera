---
title: 查询分析
description: 把 Chart、Table、Metric、SQL 与血缘 Node 组合为一个受治理 Surface。
---

这不是 `QueryArtifact`。它由 `layout.stack`、`data.metric`、`data.chart`、
`data.table` 与 `data.query-details` Node 组合而成。这些 Node 可以共享同一个
pinned Resource version；SQL 与血缘仍是受策略控制的 render projection，不会成为浏览器可执行输入。
