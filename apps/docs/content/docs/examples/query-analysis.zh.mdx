description: 使用一个可审查的 Query Artifact 渲染图表、表格、SQL 和来源血缘。

当用户需要在同一个答案中查看趋势图和精确结果行时，使用 Query Artifact。
SQL 与血缘保持可审查，但不会成为浏览器中的可执行输入。
