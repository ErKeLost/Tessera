This answer is not a `QueryArtifact`. It is a `layout.stack` composition of
`data.metric`, `data.chart`, `data.table`, and `data.query-details` nodes. The
nodes bind typed pinned Resources from the same governed query execution and
share its evidence and provenance. Chart and Table can reuse a dataset version
only when their Dataset Envelope and schema match; SQL and lineage remain
policy-controlled render projections rather than executable browser input.
