description: Compose a responsive operational snapshot from orthogonal Component Contracts.

This surface uses `layout.grid`, `layout.section`, `data.metric`, `data.chart`,
and `content.callout`. Each metric is an independent validated node, and any
follow-up request crosses a declared event port and the Host Action boundary.
