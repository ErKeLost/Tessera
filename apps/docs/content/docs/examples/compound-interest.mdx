---
title: Compound Interest
description: Compose governed numeric controls with host-computed Metric and Chart results.
---

There is no Calculator business component. The Agent composes `control.group`
and numeric `control.filter` nodes with `data.metric` and `data.chart`. Applying
the controls emits a declared HostIntent; trusted host code performs the
calculation and returns new surface operations. The model never supplies an
executable formula or browser code.
