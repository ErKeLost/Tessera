title: Examples
description: Data Agent surfaces rendered through the Tessera Agent Generative UI chain.
---

Each example is a composition of the same 12 Component Contracts. The model
proposes declarative nodes; trusted surface events enter `SurfaceController`,
and `GenerativeSurface` renders them through the official `RendererRegistry`.
No example uses model-generated JSX or a fixed business Artifact renderer.
