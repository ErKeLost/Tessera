---
title: 复利计算
description: 组合受治理数值控件与 Host 计算后的 Metric、Chart 结果。
---

这里不存在 Calculator 业务大组件。Agent 使用 `control.group` 与数值型
`control.filter` Node，并组合 `data.metric`、`data.chart`。应用控件时只发出已声明的
HostIntent；可信 Host 代码执行计算，再返回新的 Surface Operation。模型不会提供可执行公式或浏览器代码。
