Tessera Agent is a database-aware assistant for teams that need answers they can
inspect, reproduce, and act on. It discovers the connected catalog, plans against
the available relations, executes bounded reads, and returns evidence with every
result.

This site documents the **Agent product**: how to connect a database, shape the
tool contract, understand the run loop, operate the approval boundary for
mutations, and use the generated analysis views built into Studio.

## The request lifecycle

```text
question
  -> catalog scope
  -> semantic plan
  -> bounded read
  -> evidence + diagnostics
  -> answer or approved mutation
```

The model never receives connection secrets or an unrestricted database
surface. Tessera owns the catalog snapshot, authorization decision, connector
execution, error details, and the terminal result that is shown to the user.
