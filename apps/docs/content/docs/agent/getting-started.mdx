## Prerequisites

- Node.js 24 or later, or Bun 1.3 or later
- PostgreSQL, MySQL, SQLite, or Turso
- A model-provider API key

Prefer a read-only database user. SQLite and Turso are always read-only in
Studio.

## Start Studio

Run Studio from the directory that contains `tessera.config.ts`:

```bash
npx data-elements@latest studio
```

The CLI searches upward for the config and starts the local workspace at
`http://127.0.0.1:4317`.

For a temporary connection, pass one database URL:

```bash
npx data-elements@latest studio postgresql://readonly:password@127.0.0.1:5432/warehouse
npx data-elements@latest studio mysql://readonly:password@127.0.0.1:3306/warehouse
npx data-elements@latest studio file:/absolute/path/to/warehouse.db
TURSO_AUTH_TOKEN=... npx data-elements@latest studio libsql://warehouse-org.turso.io
```

Positional URLs can appear in shell history or process listings. Use a config
file and environment variables for durable projects.

## Complete the first analysis

1. Confirm the connection in the workspace header.
2. Open **Data explorer** and inspect the catalog.
3. Start a thread and ask a specific business question.
4. Review the catalog, planning, execution, verification, and narration stages.
5. Inspect the bounded evidence attached to the answer.

Continue with [configuration](/docs/agent/configuration) for a durable setup or
[database connections](/docs/agent/databases) for engine-specific options.
