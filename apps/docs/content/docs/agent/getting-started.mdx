Tessera Studio is the local workspace for Tessera Agent. It includes the chat
interface, database connectors, governed tools, session history, approvals, and
generated analysis views. There is no separate UI package to install.

## Requirements

- Node.js 24 or later
- Bun 1.3 or later when developing from this repository
- PostgreSQL, MySQL, SQLite, or Turso
- A model-provider API key

## Start with a database URL

The fastest path is the published Studio executable:

```bash
npx @open-tessera/studio@latest postgresql://readonly:password@127.0.0.1:5432/warehouse
```

SQLite and Turso use their own connection forms:

```bash
npx @open-tessera/studio@latest file:/absolute/path/to/warehouse.db
TURSO_AUTH_TOKEN=... npx @open-tessera/studio@latest libsql://warehouse-org.turso.io
```

Studio prints its local URL and binds to `127.0.0.1` by default. Keep database
credentials and provider keys on the server; they are never sent to the browser.

## Configure a project

For a repeatable setup, add `tessera.config.ts` to the project and run the same
command without a URL argument:

```ts
import { defineTesseraConfig } from "@open-tessera/studio";

export default defineTesseraConfig({
  database: {
    url: process.env.DATABASE_URL!,
    maxRows: 5_000,
    statementTimeoutMs: 30_000,
  },
  llm: {
    model: "openrouter/qwen/qwen3.8-27b",
  },
});
```

Provider credentials are read from the matching server environment variable,
such as `OPENROUTER_API_KEY`, `OPENAI_API_KEY`, or `ANTHROPIC_API_KEY`.

## Ask a grounded question

Try a question that needs connected data, for example:

> Compare monthly revenue for the last six months and show the result as a chart.

Tessera chooses one database path, executes a bounded query, verifies the
result, and then returns the answer. When the result matches an available
analysis recipe, the same response includes a generated view rendered by
Studio. You do not request a UI tool or name an internal renderer.

Continue with [configuration](./configuration), [database connections](./databases),
and the [run workflow](./run-workflow).
