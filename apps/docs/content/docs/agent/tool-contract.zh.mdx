## 面向模型的 Tool

```text
inspect_current_context  -> 服务端绑定的当前数据上下文
inspect_catalog          -> 针对一个问题的语义 Catalog 切片
describe_data            -> 已检查实体的受限详细信息
probe_data               -> 固定且受限的发现 Probe
run_analysis             -> 根据语义 Draft 执行只读分析
```

Tool 只接受当前 Catalog 返回的语义 ID。它们不接受 SQL、连接字符串、凭据、物理
关系名、Compiler 输出 ID 或任意查询限制。最终答案必须建立在经过验证的
`run_analysis` 结果上。

## Trust Boundary

| 边界 | 允许 | 永远不允许 |
| --- | --- | --- |
| Model | 语义切片、Opaque ID、受限证据 | SQL、凭据、物理表名 |
| Browser | 脱敏生命周期、安全叙述、已验证 Artifact | 原始 Tool 参数、私有 Trace、Connector 访问 |
| Studio Server | Authentication Hook、编排、过滤、持久化 | 绕过宿主授权 |
| Data Agent | 实时 Catalog、签名 Scope、类型化 Draft、受限结果 | 调用方 SQL 或超出 Scope 的分析 |
| Write Surface | 类型化 Mutation、用途、幂等键、Approval | 只读分析中的隐式写入或自由 SQL |
