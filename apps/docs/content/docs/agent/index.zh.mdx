---
title: Tessera Data Agent
description: 把业务问题转化为受限、可审查分析的受治理工作台。
---

Tessera Data Agent 是一个 Local-first 数据分析产品。它把自然语言问题转化为
语义计划、受限的只读查询、经过验证的证据和 Markdown 答案，同时避免把数据库
凭据或原始 Runtime Payload 暴露给浏览器。

![Tessera Data Agent Studio 架构](/diagrams/tessera-data-agent-studio.svg)

模型只提出语义意图。Catalog 发现、授权范围、查询编译、执行限制、结果验证、
证据和发布都由 Tessera 掌控。
