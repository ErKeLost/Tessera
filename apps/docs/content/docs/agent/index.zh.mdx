---
title: Tessera Agent
description: 构建一个能解释每次查询与每个决策的受治理 Data Agent。
---

Tessera Agent 把自然语言问题转化为语义计划、有上限的查询和经过验证的 Evidence，
同时避免把 Credential 或无限制的数据库表面暴露给模型。

![Tessera Agent Studio 架构](/diagrams/tessera-data-agent-studio.svg)

模型只提出分析意图。Catalog 发现、授权范围、查询编译、执行限制、具体 Diagnostic 和
Evidence 发布，以及回答中出现的生成式分析界面，都由 Tessera 掌控，并由 Studio 在同一条回答中渲染。

```text
问题 -> Catalog 范围 -> 语义计划 -> 有上限的执行 -> Evidence -> 回答
```
