---
title: Tessera Agent
description: 用于证明 Tessera Agent 终局 Generative UI 架构的受治理 Data Agent 工作流。
---

Tessera Agent 把自然语言问题转化为语义计划、受限只读查询、经过验证的 Evidence 与
Committed Generative UI Surface，同时避免把 Credential、原始 Tool Payload 或 Query Row 暴露给模型。

![Tessera Agent Studio 架构](/diagrams/tessera-data-agent-studio.svg)

模型先提出语义分析意图，再提议声明式 UI Node。Catalog 发现、授权范围、查询编译、执行限制、
Resource 与 Evidence 发布、UI 校验、Commit、可信事件和渲染都由 Tessera 掌控。

```text
受治理分析 -> Resource/Evidence Offer -> present_ui -> Committed Revision
-> SurfaceEventStream -> SurfaceController -> GenerativeSurface -> RendererRegistry
```
