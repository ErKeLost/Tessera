---
title: Tessera Data Agent
description: A governed workspace that turns business questions into bounded, inspectable analysis.
---

Tessera Data Agent is a local-first analysis product. It converts a natural
language question into a semantic plan, a bounded read-only query, verified
evidence, and a Markdown answer without exposing database credentials or raw
runtime payloads to the browser.

![Tessera Data Agent Studio architecture](/diagrams/tessera-data-agent-studio.svg)

The model proposes semantic intent. Tessera owns catalog discovery,
authorization scope, query compilation, execution limits, verification,
evidence, and publication.
