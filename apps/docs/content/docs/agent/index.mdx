---
title: Tessera Agent
description: Build a governed data agent that can explain every query and every decision.
---

Tessera Agent converts a natural-language question into a semantic plan, a
bounded query, and verified evidence without exposing credentials or an
unrestricted database surface to the model.

![Tessera Agent Studio architecture](/diagrams/tessera-data-agent-studio.svg)

The model proposes analysis intent. Tessera owns catalog discovery,
authorization scope, query compilation, execution limits, diagnostic detail,
Evidence publication, and the generated analysis view shown with the answer.
Studio renders those presentation results as part of the same response.

```text
question -> catalog scope -> semantic plan -> bounded execution -> evidence -> answer
```
