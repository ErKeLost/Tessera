---
title: 生成式分析视图
description: Tessera Agent 如何把可信 Query Resource 转换成安全、结构化的回答界面。
---

Tessera Agent 可以在文字回答旁返回结构化分析视图。这项能力内置在 Tessera Studio 中，
与回答正文共享同一套数据库、权限、Memory 与 Transport 边界。

## 唯一回答链路

```text
问题
-> 数据库 Tool Step
-> Verified Resource + Evidence
-> Final Presentation Language
-> 服务端校验与 Commit
-> Typed AI SDK Data Part
-> Studio Renderer
```

模型不会调用 UI Tool。数据库 Tool 产生可信 Resource 后，Tessera 的 Mastra Output Processor
才会为最终模型 Step 提供受限的呈现词汇。完整 Statement 在 Stream 中被编译，Presentation
Source Text 不会作为聊天正文显示。

只有完整声明通过 Schema、Resource Binding、Authority 与 Commit 检查后，Processor 才发布
视图。非法输出最多触发一次受限 Processor Retry；Retry 会关闭 Domain Tool，因此修正视图时
不会再次查询数据库，也不会制造 Tool Loop。

## 数据始终由 Tessera 掌控

Query Row 不会复制进模型编写的声明。模型只能把 Chart 或 Metric 绑定到 Opaque Resource，
并选择本轮明确提供的 Column。Tessera 只在渲染前为当前 Node 解析并校验数据集。

浏览器拿不到数据库 Credential、Connector Handle、Authority Object、Compiler State 或原始模型
Proposal。它只接收原生 AI SDK Part，以及已经 Commit 的 Typed Analysis-view Data Part。

## 当前视图词汇

Tessera 当前使用六个分析概念：

- Report
- Stack
- Grid
- Metric
- Insight
- Data Chart

Data Chart 包含 17 个经过审计的 Recipe。Recipe 只能选择信息结构和合法 Column Binding，不能
携带任意 CSS、颜色、Callback、React Props、JavaScript、SVG Markup、URL、SQL 或 Tool Name。

Renderer 根据需要使用本地 shadcn/ui 风格 Primitive 与 Recharts。主题值来自 Tessera CSS
Token，模型输出不能控制主题。

## 失败与刷新

Parse、Validation、Policy、Timeout、Abort 或 Conflict 失败时，最后一次 Committed View 仍然
保留。Multi-step 回答中，AI SDK 负责装配 UI Message，Tessera 在每次 `onStepEnd` 对同一个
Assistant Message 做 Checkpoint。累积更新只替换旧 Surface Snapshot，因此刷新后只恢复一个
最新视图，不会叠加多份副本。
