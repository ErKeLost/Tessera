---
title: Data-agent proof gates
description: Deterministic, product-quality, security, and rendering gates Tessera Agent must pass before Open Generative extraction.
---

The current goal is not to prove that a model can emit component JSON. It is to prove that Tessera Agent can turn governed query results into useful, trustworthy, responsive, interactive analysis while preserving last-good through malformed output, interrupted streams, authority changes, and conflicts.

The fixed scope is 12 orthogonal Component Contracts, complete shadcn/ui chart coverage, and at least 100 golden prompts spanning KPI, trend, comparison, distribution, detail inspection, filters, empty states, auditability, streaming, edits, HostIntent, resume, and conflicts.

No query rows may appear in model context, proposals, Documents, Revisions, history, or ordinary logs. Resource access remains grant-bound and cursor-based. Fabricated offers, out-of-slice contracts, interactive previews, browser-side HostIntent execution, approval replay, or invalid stream identity are hard failures.

First-proposal structural validity must reach 95%, bounded-repair commit success 99%, fabricated references zero, and snapshot/operation canonical divergence zero. Every successful golden case also checks information structure, primary-view choice, evidence, and chart/table semantic parity.

Each Contract requires an exact renderer, resolved-props validation, full state fixtures, accessibility coverage, and a node error boundary. All chart recipes require stable responsive sizing, reduced-motion behavior, accessible summaries, and an equivalent table or text view.

Only after all deterministic and model-evaluation gates pass may the framework-neutral core be extracted into a separate Open Generative project.
