---
title: Analysis-view quality gates
description: The deterministic, security, rendering, and product gates for Tessera Agent's generated views.
---

The goal is not to prove that a model can emit component-shaped text. Tessera
must turn governed query results into useful, trustworthy, responsive analysis
while preserving the last committed answer through malformed output,
interrupted streams, authority changes, and conflicts.

## Fixed scope

- Six analytical concepts: report, stack, grid, metric, insight, and data chart.
- One chart contract with 17 audited recipes.
- Golden prompts covering selection, column binding, streaming, refresh,
  authority changes, retry, and conflict behavior.
- Multiple valid views for the same resource, proving the system is not a
  hidden fixed query renderer.

## Hard safety gates

- Query rows do not enter presentation prompts, declarations, ordinary logs,
  or browser tool summaries.
- The model cannot reference a resource, column, evidence item, view type, or
  action that Tessera did not offer for the current turn.
- Invalid stream identity, authority, or resource binding fails closed.
- Browser rendering cannot grant database access or execute a mutation.
- A presentation retry cannot call domain tools again.

## Quality targets

| Metric | Gate |
| --- | --- |
| Structurally valid first proposal | at least 95% |
| Successful commit after bounded repair | at least 99% |
| Fabricated references | 0 |
| Incorrect chart encoding accepted | 0 |
| Duplicate assistant checkpoints after refresh | 0 |
| Difference between live and restored final view | 0 |

Every successful case also checks recipe choice, column mapping, information
hierarchy, source fidelity, and an equivalent table or text view.

## Renderer gates

All 17 recipes require stable responsive sizing, reduced-motion behavior, an
accessible name and summary, keyboard-safe interaction, theme-token coverage,
and a semantically equivalent non-chart view. The documentation gallery renders
the same fixtures and renderer code used by Tessera Studio; documentation-only
replicas do not count.

Run deterministic tests without production credentials. Provider evaluation,
desktop/mobile visual regression, accessibility reports, and dependency
integrity checks are release gates for the Agent product.
