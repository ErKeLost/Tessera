---
title: 分析视图质量门槛
description: Tessera Agent 生成式分析视图的确定性、安全、渲染与产品验收标准。
---

目标不是证明模型能输出“像组件的文本”。Tessera 必须把受治理的 Query Result 转换成有用、
可信、响应式的分析，并且在非法输出、Stream 中断、Authority 变化与 Conflict 中保住最后一次
Committed Answer。

## 固定范围

- 六个分析概念：Report、Stack、Grid、Metric、Insight 与 Data Chart。
- 一份 Chart Contract，包含 17 个经过审计的 Recipe。
- Golden Prompt 覆盖 Recipe 选择、Column Binding、Streaming、刷新、Authority 变化、Retry 与 Conflict。
- 同一 Resource 可以得到多种合理视图，证明系统不是隐藏的固定 Query Renderer。

## 硬性安全门槛

- Query Row 不进入 Presentation Prompt、声明、普通日志或浏览器 Tool 摘要。
- 模型不能引用本轮未提供的 Resource、Column、Evidence、View Type 或 Action。
- Stream Identity、Authority 或 Resource Binding 非法时 Fail Closed。
- 浏览器渲染不能授予数据库访问权，也不能执行 Mutation。
- Presentation Retry 不能再次调用 Domain Tool。

## 质量指标

| 指标 | 门槛 |
| --- | --- |
| 首次 Proposal 结构有效率 | 不低于 95% |
| 有界 Repair 后 Commit 成功率 | 不低于 99% |
| 虚构引用 | 0 |
| 被接受的错误 Chart Encoding | 0 |
| 刷新后的重复 Assistant Checkpoint | 0 |
| Live 与恢复后的最终视图差异 | 0 |

每个成功 Case 还要检查 Recipe 选择、Column Mapping、信息层级、Source Fidelity，以及语义等价的
Table 或 Text View。

## Renderer 门槛

17 个 Recipe 都必须具备稳定的 Responsive Size、Reduced Motion、Accessible Name 与 Summary、
Keyboard-safe Interaction、Theme Token Coverage，以及语义等价的非图表视图。文档 Gallery 使用
Tessera Studio 相同的 Fixture 与 Renderer Code；文档专用仿制实现不算通过。

确定性测试不依赖生产 Credential。Provider Eval、Desktop/Mobile Visual Regression、
Accessibility Report 与 Dependency Integrity 都是 Tessera Agent 的发布门槛。
