Tessera Studio 是 Tessera Agent 的本地工作区，已经包含对话界面、数据库 Connector、受治理
Tool、会话历史、审批与生成式分析视图，不需要再安装独立 UI Package。

## 环境要求

- Node.js 24 或更高版本
- 从本仓库开发时使用 Bun 1.3 或更高版本
- PostgreSQL、MySQL、SQLite 或 Turso
- 模型供应商 API Key

## 使用数据库 URL 启动

最快方式是直接运行已经发布的 Studio：

```bash
npx @open-tessera/studio@latest postgresql://readonly:password@127.0.0.1:5432/warehouse
```

SQLite 与 Turso 使用各自的连接形式：

```bash
npx @open-tessera/studio@latest file:/absolute/path/to/warehouse.db
TURSO_AUTH_TOKEN=... npx @open-tessera/studio@latest libsql://warehouse-org.turso.io
```

Studio 会输出本地访问地址，默认只监听 `127.0.0.1`。数据库凭据与模型 Key 必须留在服务端，
不会发送到浏览器。

## 配置项目

需要可重复配置时，在项目中添加 `tessera.config.ts`，然后不带 URL 参数运行同一个命令：

```ts
import { defineTesseraConfig } from "@open-tessera/studio";

export default defineTesseraConfig({
  database: {
    url: process.env.DATABASE_URL!,
    maxRows: 5_000,
    statementTimeoutMs: 30_000,
  },
  llm: {
    model: "openrouter/qwen/qwen3.8-27b",
  },
});
```

供应商凭据从对应的服务端环境变量读取，例如 `OPENROUTER_API_KEY`、`OPENAI_API_KEY`
或 `ANTHROPIC_API_KEY`。

Tessera 会选择一条数据库路径、执行受限查询、校验结果并返回回答。当结果适合现有分析 Recipe 时，
同一条回答会包含由 Studio 直接渲染的分析视图。用户不需要请求 UI Tool，也不需要知道内部 Renderer 名称。
