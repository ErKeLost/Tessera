Tessera Agent separates model-authored declarations from host-owned data,
identity, validation, authority, state, effects, persistence, commit, and
rendering. The model never produces executable UI code or a trusted runtime
object.

## One canonical path

```text
user question + host-authorized resource offers
-> frozen CatalogSetSlice
-> model proposes declarative nodes
-> compiler normalizes, validates, authorizes, and commits
-> HostServer publishes a trusted SurfaceEventStream
-> SurfaceController replays events and resolves node projections
-> GenerativeSurface traverses the canonical graph
-> RendererRegistry resolves an exact Component Contract renderer
-> @open-generative/ui renders Tessera Agent's shadcn/Recharts components
```

There is no `ArtifactPart`, browser decoder, `ArtifactRenderer`, legacy
compatibility facade, or second per-artifact rendering path in this architecture.
Raw model output never reaches React.

## Package boundaries

| Boundary | Package | Responsibility |
| --- | --- | --- |
| Canonical values and wire protocols | `@open-generative/protocol` | Documents, operations, streams, IDs, hashes, limits, and diagnostics |
| Contract identity and manifests | `@open-generative/catalog` | Immutable Component Contracts, Catalog slices, placement, and renderer capability negotiation |
| Proposal acceptance | `@open-generative/compiler` | Server-only decode, normalize, validate, repair, policy, and commit gates |
| Deterministic state | `@open-generative/runtime` | Document, preview, state, replay, revision DAG, and migration reducers |
| Host orchestration | `@open-generative/server` | Sessions, transactions, event journal, authority, and trusted publication |
| Browser control | `@open-generative/client` | Trusted event replay, resolved node projections, resume, and host commands |
| Resource data | `@open-generative/resources` | Server-only schemas, grants, projections, windows, and evidence |
| Effects | `@open-generative/capabilities` | Server-only action policy, approval, idempotency, effects, and receipts |
| React binding | `@open-generative/react` | `GenerativeSurface`, exact `RendererRegistry`, placement, and system surfaces |
| Data-agent contracts | `@open-generative/components` | The 12 contracts, props schemas, chart specs, recipes, and fixtures |
| Data-agent UI | `@open-generative/ui` | Official shadcn/Recharts node renderers and registry factory |

Framework adapters may translate transport details, but they cannot own or
replace these semantics. Browser code must not import compiler, server,
resource, capability, credentials, prompt examples, or signing material.

## Current Component Contract slice

The proof uses 12 orthogonal contracts:

- Layout: `layout.stack`, `layout.grid`, `layout.section`
- Content: `content.text`, `content.callout`, `content.empty`
- Data: `data.metric`, `data.table`, `data.chart`, `data.query-details`
- Controls: `control.filter`, `control.group`

Trend, comparison, funnel, cohort, anomaly, forecast, and data-quality
experiences are composition recipes, not additional protocol types. This keeps
the model-facing slice small while allowing product-quality analytical surfaces.

## Commit and preview

Layout and safe content may appear through a validated read-only preview.
Resource-backed data and state-bound controls commit atomically. Preview
renderers receive no event emitter, so incomplete content cannot trigger host
commands. A failed proposal preserves the last-good committed revision.

Resource payloads do not enter the canonical document. `SurfaceController`
materializes and validates resolved props for one node from trusted,
grant-bound projections immediately before rendering.
