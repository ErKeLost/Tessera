---
title: State and actions
description: Keep local UI state fast while sending intentional actions to the agent.
---

Tessera Agent uses three state owners:

- **Authoritative business state** lives on the server.
- **Ephemeral interaction state** lives in the artifact. Slider motion updates
  charts immediately and does not consume model tokens.
- **Durable user state** lives in host-controlled storage.

Wrap renderers with `TesseraPreviewProvider` to receive structured events:

```tsx
<TesseraPreviewProvider
  onAction={(event) => {
    // event.artifactId, event.action, event.payload
  }}
>
  <ArtifactRenderer artifact={artifact} />
</TesseraPreviewProvider>
```

The host decides whether an event remains telemetry, invokes a tool directly,
or becomes a user message for the model. This prevents incidental controls from
creating expensive conversational turns.
