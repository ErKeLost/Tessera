---
title: 分析选择
description: Tessera 如何选择数据库 Tool 并生成有依据的最终回答。
---

处理数据问题时，Tessera 只做一个权威决定：如何取得可信数据。回答组合没有数据库权限，也不能
改变之前选择的查询路径。

## 数据库路径选择

Agent Instruction 与类型化 Tool Schema 会引导模型从两条路径中选择一条：

| 分析意图 | 主要路径 |
| --- | --- |
| 物理 Schema、明确 SQL、精确行数据 | `list_database -> execute_sql` |
| 语义指标、维度、排行、趋势 | `search_data_context -> prepare_analysis -> execute_sql(analysisRef)` |

Tool Output 提供受限证据与稳定列元数据。无效 Tool 参数会得到结构化拒绝，不能被解释为“数据不存在”。

## 回答组合

最终模型 Step 只接收解释回答所需的已验证 Tool Output 与 Evidence。输出会在存储或发送到浏览器前
完成 Parse 和 Validate，不能包含 Credential、Raw SQL、任意 Tool Definition 或可执行内容。
