---
title: 安全模型
description: 为什么受约束的 Artifact 比模型生成的应用程序更安全。
---

Tessera Agent 将模型输出视为不可信数据。

- 未知的 Artifact kind 无法通过验证。
- 未知的计算器 ID 会渲染安全回退界面。
- 计算器公式是已注册的 TypeScript 函数，绝不会以字符串形式传给 `eval` 或 `Function`。
- 协议不包含 HTML、JSX、JavaScript、CSS、可执行代码 URL 或未注册组件名等字段。
- 查询溯源信息和 SQL 仅用于展示；执行由获得授权的服务端工具负责。
- 宿主应用程序仍需负责授权、数据最小化、行级访问控制和破坏性操作确认。

对于真正开放的外部微型应用程序，应使用沙箱 iframe 或 MCP App 边界，而不是削弱可信目录的约束。
