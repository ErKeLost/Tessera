以下示例展示 Schema、渲染器、操作、表格和图表如何在真实的数据智能体回答中协同工作。
每个界面都由经过验证的数据渲染，而不是由模型生成 JSX。

## 查询结果

当用户需要在一个可审查的回答中同时查看图表、精确数据行、SQL 和数据源溯源信息时，
使用 Query Artifact。

<ComponentPreview
  filename="examples/credit-flow.tsx"
  code={`import { QueryArtifact } from "@/components/data-elements/query-artifact"

export function CreditFlow({ artifact }) {
  return <QueryArtifact artifact={artifact} defaultView="table" />
}`}
>
  <QueryDemo />
</ComponentPreview>
