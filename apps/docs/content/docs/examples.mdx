Examples show how schemas, renderers, actions, tables, and charts work together
inside a real data-agent response. Every interface below is rendered from
validated data rather than model-generated JSX.

## Query result

Use Query Artifact when people need a chart, exact rows, SQL, and source
lineage in one inspectable answer.

<ComponentPreview
  filename="examples/credit-flow.tsx"
  code={`import { QueryArtifact } from "@/components/data-elements/query-artifact"

export function CreditFlow({ artifact }) {
  return <QueryArtifact artifact={artifact} defaultView="table" />
}`}
>
  <QueryDemo />
</ComponentPreview>
