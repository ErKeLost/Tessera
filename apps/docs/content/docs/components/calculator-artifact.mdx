The model selects a registered `calculatorId` and supplies initial values. The
runtime clamps those values to catalog bounds and recalculates locally—no model
call is needed while a slider is moving.

  code={`import { CalculatorArtifact } from "@/components/tessera-agent/calculator-artifact"

  return (

## Usage

Calculators are catalog entries, not executable formulas supplied by the
model. Built-in definitions include `compound-interest` and `loan-payment`.

<CodeExample
  filename="components/financial-model.tsx"
  code={`"use client"

import { CalculatorArtifact } from "@/components/tessera-agent/calculator-artifact"
import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"

export function FinancialModel({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={(event) => audit(event)}>
      <CalculatorArtifact
        artifact={artifact}
        locale="en-US"
        onClose={() => dismissArtifact(artifact.id)}
      />
    </TesseraPreviewProvider>
  )
}`}
/>

### Actions

| Action | Payload | When it fires |
| --- | --- | --- |
| `calculator-change` | `{ values }` | A control changes and values have been normalized. |
| `copy-formula` | `{ values }` | The user copies the trusted formula and substitution. |
