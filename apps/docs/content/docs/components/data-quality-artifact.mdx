---
title: Data Quality Artifact
description: Pair an overall quality score with inspectable freshness, completeness, and integrity checks.
---

Data Quality Artifact makes the evidence behind a score visible. Every check
has an explicit status and explanation, with optional observed and threshold
values for fast diagnosis.

## Usage

Keep the overall score within `0–100`. Check statuses are the closed set
`passed`, `warning`, and `failed`; icons come from `lucide-react` and remain
consistent across themes.

<CodeExample
  filename="components/model-health.tsx"
  code={`"use client"

import { DataElementsProvider } from "@/components/data-elements/bridge"
import { DataQualityArtifact } from "@/components/data-elements/data-quality-artifact"

export function ModelHealth({ artifact }) {
  return (
    <DataElementsProvider onAction={(event) => inspectCheck(event.payload)}>
      <DataQualityArtifact artifact={artifact} />
    </DataElementsProvider>
  )
}`}
/>
