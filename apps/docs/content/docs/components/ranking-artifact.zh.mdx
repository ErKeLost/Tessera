## 使用方式

提供 1 至 50 个按非递减名次排列的条目。条目 ID 必须唯一；并列时可以重复使用同一名次。
`highlightId` 为可选字段，但提供后必须引用当前载荷中的某个条目。

<CodeExample
  filename="components/channel-ranking.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { RankingArtifact } from "@/components/tessera-agent/ranking-artifact"

export function ChannelRanking({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={({ payload }) => openChannel(payload.itemId)}>
      <RankingArtifact artifact={artifact} locale="zh-CN" />
    </TesseraPreviewProvider>
  )
}`}
/>

### 排名字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rank` | `positive integer` | 由可信生产者显式提供的名次。 |
| `change` | `number` | 当前条目的可选有符号百分比变化。 |
| `highlightId` | `string` | 可选的语义高亮条目 ID。 |

选择条目会发出 `ranking-item-select`，载荷为 `{ itemId, rank }`。
