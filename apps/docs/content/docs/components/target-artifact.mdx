title: Target Artifact
description: Show actual-versus-target progress with explicit direction, trusted status, baseline, and deadline context.
---

Use Target Artifact when one measurable objective is the answer. The payload
states whether higher or lower values are better and supplies the trusted
status explicitly; the renderer never fabricates business thresholds.

## Usage

Provide `actual`, `target`, `direction`, and a status computed by a trusted
business rule. Add `baseline` when progress should be measured from a known
starting point, especially for zero or negative targets.

### Target fields

| Field | Type | Description |
| --- | --- | --- |
| `direction` | `higher-is-better \| lower-is-better` | Defines how progress toward the target is interpreted. |
| `status` | `achieved \| on-track \| at-risk \| off-track` | Trusted business status; it is not inferred by the renderer. |
| `baseline` | `number` | Optional starting point used to calculate progress. |

Target Artifact is intentionally read-only and emits no action event.
