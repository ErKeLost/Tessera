Driver Artifact answers **what moved the metric**. Its waterfall-style bridge
shows the starting value, positive and negative contributions, ending value,
and any unreconciled remainder.

## Selection rule

Use only additive, non-overlapping contributions from a trusted decomposition.
Correlation is not contribution. Selecting a driver emits `driver-select` with
its ID and index.
