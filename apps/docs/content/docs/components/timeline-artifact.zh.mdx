当业务事件或里程碑的时间与状态是答案的一部分时，使用 Timeline Artifact。它让时间顺序
保持明确，同时无需模型组合任意布局基础组件。

## 使用方式

每个事件都需要唯一 ID、ISO 时间戳、标签、说明以及五种封闭状态之一。`order` 独立控制
展示顺序，`timeZone` 则控制确定性的日期格式。

<CodeExample
  filename="components/rollout-timeline.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { TimelineArtifact } from "@/components/tessera-agent/timeline-artifact"

export function RolloutTimeline({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={({ payload }) => inspectEvent(payload.eventId)}>
      <TimelineArtifact artifact={artifact} locale="zh-CN" />
    </TesseraPreviewProvider>
  )
}`}

### 事件状态

`planned`、`in-progress`、`completed`、`blocked` 和 `info` 是仅有的合法状态。
Renderer 会把每种状态映射为稳定的 shadcn 语义样式。

选择事件会发出 `timeline-item-select`，载荷为 `{ eventId }`。
