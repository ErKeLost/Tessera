> **Historical design input:** This page preserves the component design, examples, and visual intent of an earlier fixed Artifact recipe. It is not a current Component Contract or public installation API. The current data-agent Generative UI composes this experience from the [12 orthogonal Contracts](/docs/components/generative-ui-catalog).


Use Query Artifact when an authoritative data tool returns rows and people need
to inspect both a visualization and exact values. The displayed SQL is always
read-only—the component never executes it.

## Usage

Wrap artifacts with `TesseraPreviewProvider` once, then render validated data.

<CodeExample
  filename="app/analytics/page.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge";
import { QueryResultSurface } from "@/components/tessera-agent/query-artifact";

export default function AnalyticsPage() {
  return (
    <TesseraPreviewProvider onAction={(event) => sendToAgent(event)}>
      <QueryResultSurface artifact={queryResult} defaultView="chart" />
    </TesseraPreviewProvider>
  )
}`}
/>
