Use Breakdown Artifact to answer **who contributed to the result**. It is a
ranked analytical answer, not a generic bar chart: every row preserves its
value, share of total, optional period change, and drill-down action.

## Selection rule

Use mutually understandable categories measured with the same metric. Do not
use it for sequential stages, overlapping shares, or raw observation ranges.
Selecting a row emits `breakdown-item-select` with its ID and rank.
