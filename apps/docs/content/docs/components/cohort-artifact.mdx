Cohort Artifact renders a compact heatmap with cohort size and incomplete
recent periods kept explicit. Rows align by cohort age, so calendar totals
cannot be mistaken for retention.

## Selection rule

Use identical cohort membership and period definitions for every row. Use
`null` for periods that have not matured, never zero. Selecting a populated
cell emits `cohort-cell-select` with cohort, period, and value.
