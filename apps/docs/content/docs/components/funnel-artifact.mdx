Use Funnel Artifact for ordered stages that represent the same cohort moving
through a process. It is not a generic horizontal bar chart: stage order and
conversion semantics are part of the schema.

## Usage

Steps must be ordered from entry to outcome. The renderer calculates conversion
from adjacent values when `conversionFromPrevious` is omitted.

<CodeExample
  filename="components/activation-funnel.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { FunnelArtifact } from "@/components/tessera-agent/funnel-artifact"

export function ActivationFunnel({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={(event) => drillIntoStep(event.payload)}>
      <FunnelArtifact artifact={artifact} />
    </TesseraPreviewProvider>
  )
}`}
/>
