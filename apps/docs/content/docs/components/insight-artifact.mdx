Insight Artifact is for narrative findings grounded in trusted analysis. Each
item separates the headline, explanation, and optional evidence instead of
asking the model to invent an arbitrary card layout.

## Usage

Keep headlines concise and put the supporting measurement in `evidence`. The
optional recommended action is emitted as structured data, never executed by
the component itself.

<CodeExample
  filename="components/weekly-insights.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { InsightArtifact } from "@/components/tessera-agent/insight-artifact"

export function WeeklyInsights({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={(event) => continueAnalysis(event)}>
      <InsightArtifact artifact={artifact} />
    </TesseraPreviewProvider>
  )
}`}
/>
