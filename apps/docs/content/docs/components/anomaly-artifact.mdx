Anomaly Artifact is for exceptions that deserve attention. The agent supplies
validated observations and explanations; severity controls presentation but
never grants the model arbitrary visual styling.

## Usage

Use `low`, `medium`, and `high` severity only for prioritization. Keep the
numeric `actual`, `expected`, and signed percentage `deviation` explicit so the
surface remains auditable.

<CodeExample
  filename="components/anomaly-review.tsx"
