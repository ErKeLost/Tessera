Experiment Artifact makes a causal result inspectable. A point estimate is not
enough: the protocol requires both variants, sample sizes, an effect estimate,
a confidence interval, a significance decision, and the statistical method.

## Selection rule

Only use this component when an experiment service or approved causal analysis
computed the result. Never infer significance from two visible percentages,
and do not label observational comparisons as experiments.
