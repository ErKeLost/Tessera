Artifact Agent 是面向数据智能体的声明式界面目录。每个组件接收带版本且经过验证的载荷，
并渲染由应用程序掌控的 React，而不是模型生成的 JSX。

## 安装

npm Package 与远程 Registry 目前尚未发布。以下命令用于说明发布后可用的公开安装接口；
当前请使用仓库内的本地开发流程。

发布后，安装完整的可编辑组件目录：

```bash
npx data-elements@latest
```

发布后，也可以只添加智能体工作流所需的 Artifact：

```bash
npx data-elements@latest add query-artifact cohort-artifact experiment-artifact
```

每个 Artifact 都使用 shadcn 语义 Token，安装后仍由宿主应用程序完整掌控。在本仓库中，
可运行 `bun install`、`bun run registry:build` 与 `bun run dev` 检查相同的本地源码。
