title: Metric Artifact
description: Present high-signal KPIs as a compact, interactive operational snapshot.
---

Use Metric Artifact when a small set of values is the answer. Each card can
emit a typed selection event for drill-down without coupling the visual
primitive to data access.

## Usage

Keep the artifact focused: use one to twelve related metrics with explicit
formatting and optional change context.

<CodeExample
  filename="components/kpi-snapshot.tsx"
  code={`"use client"

import { DataElementsProvider } from "@/components/data-elements/bridge"
import { MetricArtifact } from "@/components/data-elements/metric-artifact"

export function KpiSnapshot({ artifact }) {
  return (
    <DataElementsProvider
      onAction={({ payload }) => openMetricDetail(payload.metricId)}
    >
      <MetricArtifact artifact={artifact} locale="en-US" />
    </DataElementsProvider>
  )
}`}
/>

### Metric fields

| Field | Type | Description |
| --- | --- | --- |
| `format` | `number \| compact \| currency \| percent` | Controls deterministic value formatting. |
| `change` | `number` | Signed percentage change displayed beneath the value. |
| `sentiment` | `positive \| negative \| neutral` | Optional semantic direction when numeric sign alone is insufficient. |

Selecting a card emits `metric-select` with `{ metricId }`.
