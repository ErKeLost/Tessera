Use Timeline Artifact for a sequence of business events or milestones whose
timestamps and states matter. It keeps chronology explicit without asking the
model to compose arbitrary layout primitives.

## Usage

Every event requires a unique ID, ISO timestamp, label, description, and one of
the five closed statuses. `order` controls presentation independently of input
order, while `timeZone` controls deterministic date formatting.

<CodeExample
  filename="components/rollout-timeline.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { TimelineArtifact } from "@/components/tessera-agent/timeline-artifact"

export function RolloutTimeline({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={({ payload }) => inspectEvent(payload.eventId)}>
      <TimelineArtifact artifact={artifact} locale="en-US" />
    </TesseraPreviewProvider>
  )
}`}
/>

### Event statuses

`planned`, `in-progress`, `completed`, `blocked`, and `info` are the only valid
statuses. The renderer maps each status to a stable shadcn-semantic treatment.

Selecting an event emits `timeline-item-select` with `{ eventId }`.
