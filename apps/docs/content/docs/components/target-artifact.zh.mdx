title: 目标 Artifact
description: 展示带明确方向、可信状态、基线和截止日期上下文的实际值与目标进度。
---

当答案是一个可衡量目标时，使用 Target Artifact。载荷明确说明数值越高还是越低越好，
并直接提供可信状态；Renderer 不会自行编造业务阈值。

## 使用方式

必须提供 `actual`、`target`、`direction`，以及由可信业务规则计算得到的状态。如果进度需要
从已知起点计算，请提供 `baseline`；当目标为零或负数时尤其应这样做。

  filename="components/service-target.tsx"

}`}

### 目标字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `direction` | `higher-is-better \| lower-is-better` | 定义如何解释朝目标推进的方向。 |
| `status` | `achieved \| on-track \| at-risk \| off-track` | 可信业务状态；Renderer 不会自行推断。 |
| `baseline` | `number` | 用于计算进度的可选起点。 |

Target Artifact 是只读界面，不会发出操作事件。
