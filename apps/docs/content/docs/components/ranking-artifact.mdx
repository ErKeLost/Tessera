title: Ranking Artifact
description: Present an explicit metric ranking with change context, a trusted highlight, and item-level actions.
---

Use Ranking Artifact when the answer is an ordered list of entities measured by
the same metric. The rank is part of the validated payload, so the renderer does
not invent an ordering or infer a winner from labels and prose.

## Usage

Provide one to fifty items in nondecreasing rank order. Item IDs must be unique;
duplicate rank numbers are allowed for ties. `highlightId` is optional, but when
present it must reference an item in the same payload.

<CodeExample
  filename="components/channel-ranking.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { RankingArtifact } from "@/components/tessera-agent/ranking-artifact"

export function ChannelRanking({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={({ payload }) => openChannel(payload.itemId)}>
      <RankingArtifact artifact={artifact} locale="en-US" />
    </TesseraPreviewProvider>
  )
}`}

### Ranking fields

| Field | Type | Description |
| --- | --- | --- |
| `rank` | `positive integer` | Explicit rank supplied by the trusted producer. |
| `change` | `number` | Optional signed percentage change for the same item. |
| `highlightId` | `string` | Optional item ID that receives semantic emphasis. |

Selecting an item emits `ranking-item-select` with `{ itemId, rank }`.
