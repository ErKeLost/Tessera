Tessera Agent is a catalog of declarative interfaces for data agents. Each
component accepts a versioned, validated payload and renders application-owned
React instead of model-generated JSX.

## Install

The npm packages and remote registry have not been published yet. The following
commands document the public installation interface that becomes available
after publication; use the repository-local development workflow today.

After publication, install the complete editable component catalog:

```bash
npx tessera-agent@latest
```

Or add only the artifacts needed by an agent workflow after publication:

```bash
npx tessera-agent@latest add query-artifact cohort-artifact experiment-artifact
```

Every artifact uses shadcn semantic tokens and remains owned by the host
application after installation. In this repository, run `bun install`,
`bun run registry:build`, and `bun run dev` to inspect the same source locally.
