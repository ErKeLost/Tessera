Tessera Agent now generates interfaces by composing a small, orthogonal
Component Contract catalog. The final architecture is generic, but the current
renderers, recipes, fixtures, and proof prompts are deliberately designed for
data-agent workflows.

## Current Generative UI catalog

The current source of truth contains 12 contracts:

- Layout: `layout.stack`, `layout.grid`, `layout.section`
- Content: `content.text`, `content.callout`, `content.empty`
- Data: `data.metric`, `data.table`, `data.chart`, `data.query-details`
- Controls: `control.filter`, `control.group`

`data.chart` supports all 61 shadcn/Recharts chart recipes and nine tooltip
recipes through one strict ChartSpec. Analytical experiences such as trend,
breakdown, anomaly, forecast, funnel, cohort, experiment, and data quality are
composition recipes over these primitives.

## Preserved design inputs

The remaining pages in this section are intentionally retained. They document
the fixed Artifact recipes, schemas, previews, and interaction ideas explored
before the current compositional architecture. They are **historical design
inputs**, not current protocol Contracts or public installation APIs.

Those pages still matter: they define the product quality Tessera Agent's
generated compositions must recover without reintroducing one protocol type for
every analytical shape.
