title: Current Generative UI catalog
description: The 12 Component Contracts used to prove Tessera Agent data-agent workflows.
---

The current Catalog contains only the 12 orthogonal components required by Tessera Agent data-agent workflows. The architecture is final, while product-specific component scope remains deliberately small. Trend, anomaly, forecast, funnel, and cohort experiences are recipes composed from these primitives rather than fixed business components.

| Category | Contracts |
| --- | --- |
| Layout | `layout.stack`, `layout.grid`, `layout.section` |
| Content | `content.text`, `content.callout`, `content.empty` |
| Data | `data.metric`, `data.table`, `data.chart`, `data.query-details` |
| Control | `control.filter`, `control.group` |

Layout and content contracts can commit progressively. Resource-backed data and state-bound controls commit atomically. Metric, Chart, Table, and Query Details may share one pinned Resource version, but rows remain inside the Resource Gateway and enter only a node-scoped resolved render projection.

The Catalog publishes only three HostIntent contracts: `data.export`, `surface.retry`, and `control.apply`. Local selection and view state remain browser-local. A renderer emits only a declared event port; the Host resolves its committed Action binding and authority.

`@open-generative/components` is the source of truth for Contracts, props schemas, ChartSpec, 70 chart/tooltip recipes, fixtures, and manifests. `@open-generative/components-react` maps those exact Contracts to shadcn/ui primitives and Recharts. Documentation and renderer conformance must be derived from the same Contract definitions.
