This is the Generative UI component catalog for the **Tessera Agent Data Agent**. It proves the final Open Generative architecture against the real product workflow while keeping the initial component scope deliberately focused. It is not a gallery of fixed business artifacts.

The Catalog contains the 12 orthogonal Component Contracts required by Tessera Agent. Trend, anomaly, forecast, funnel, and cohort experiences are recipes composed from these primitives rather than fixed business components.

| Category | Contracts |
| --- | --- |
| Layout | `layout.stack`, `layout.grid`, `layout.section` |
| Content | `content.text`, `content.callout`, `content.empty` |
| Data | `data.metric`, `data.table`, `data.chart`, `data.query-details` |
| Control | `control.filter`, `control.group` |

Layout and content contracts can commit progressively. Resource-backed data and state-bound controls commit atomically. Every data binding uses a typed pinned Resource that satisfies its exact Contract and may share evidence and provenance with resources from the same governed query execution. Chart and Table may reuse one dataset version only when both bind the same Dataset Envelope and schema. Rows remain inside the Resource Gateway and enter only a node-scoped resolved render projection.

The Catalog publishes only three HostIntent contracts: `data.export`, `surface.retry`, and `control.apply`. Local selection and view state remain browser-local. Identity-only inputs use `state-id-ref` or `resource-id-ref` without materializing state values or Resource payloads. A renderer enables an interaction only for that node's exact committed event port; preview nodes remain read-only.

`@open-generative/components` is the source of truth for Contracts, props schemas, ChartSpec, 70 chart/tooltip recipes, fixtures, and manifests. `@open-generative/ui` maps those exact Contracts to the official React UI primitives and Recharts. Documentation and renderer conformance must be derived from the same Contract definitions.
