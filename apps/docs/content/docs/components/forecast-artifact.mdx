It is not a current Component Contract or public installation API. The current data-agent Generative UI composes this experience from the [12 orthogonal Contracts](/docs/components/generative-ui-catalog).


Forecast Artifact shows actuals and projected values as separate series. The
confidence interval is declarative data, and the renderer owns the trusted
Recharts composition.

<ComponentPreview
  filename="forecast-artifact-example.tsx"

## Usage

Each point must contain at least an `actual` or `forecast` value. Add `lower`
and `upper` only when the forecasting tool returns a meaningful confidence
interval.

<CodeExample
  filename="components/revenue-forecast.tsx"
  code={`import { ForecastArtifact } from "@/components/tessera-agent/forecast-artifact"

export function RevenueForecast({ artifact }) {
  return <ForecastArtifact artifact={artifact} locale="en-US" />
}`}
/>
