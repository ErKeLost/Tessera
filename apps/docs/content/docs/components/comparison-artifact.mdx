---
title: Comparison Artifact
description: Compare several options across stable criteria and surface a clear recommendation.
---

Use this artifact when every option shares the same criteria. A row can mark a
winner without forcing qualitative information into an artificial numeric
score.

<ComponentPreview
  code={`import { ComparisonArtifact } from "@/components/tessera-agent/comparison-artifact"

export function WarehouseComparison() {
  return (
    <ComparisonArtifact
      artifact={{
        protocolVersion: "1.0",
        kind: "comparison",
        id: "warehouse-comparison",
        title: "Choose a warehouse",
        description: "Compare the criteria that matter for this workload.",
        subjectLabel: "Criteria",
        subjects: [
          { id: "snowflake", label: "Snowflake" },
          { id: "bigquery", label: "BigQuery" },

              bigquery: "Low",
              clickhouse: "Very low",
            },
            winnerId: "clickhouse",
          },
        ],
        recommendation: "Prefer managed operations for this team.",
      }}
    />
  )
}`}

## Usage

Subject IDs are the stable keys shared by each criterion's `values` object and
its optional `winnerId`.

<CodeExample
  filename="components/decision-support.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { ComparisonArtifact } from "@/components/tessera-agent/comparison-artifact"

export function DecisionSupport({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={(event) => saveDecision(event)}>
      <ComparisonArtifact artifact={artifact} />
    </TesseraPreviewProvider>
  )
}`}
/>

### Limits

| Collection | Limit | Why |
| --- | --- | --- |
| `subjects` | 2–8 | Preserves comparison readability and horizontal scanning. |
| `criteria` | 1–24 | Keeps generated surfaces useful without becoming a raw spreadsheet. |

Selecting the recommendation emits `recommendation-select` with the exact
recommendation text.
