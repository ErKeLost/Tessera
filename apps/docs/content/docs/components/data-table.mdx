---
title: Data Table
description: Search, sort, paginate, and format validated query rows without hiding exact values.
---

Data Table is the exact-value companion to a chart. It derives column labels,
types, and formatting from the validated Query Artifact schema and keeps all
searching, sorting, and pagination local.

<ComponentPreview
  filename="data-table-example.tsx"
  code={`import { DataTable } from "@/components/tessera-agent/data-table"

export function CreditLedgerTable({ queryResultSurface }) {
  return (
    <DataTable
      artifact={queryResultSurface}
      locale="en-US"
      pageSize={5}
      searchable
    />
  )
}`}
>
  <TableDemo />
</ComponentPreview>

## Installation

Data Table currently ships with the Query Artifact registry entry because the
two components share the same validated schema and formatting utilities.

<InstallCommand name="query-artifact" />

## Usage

Pass a validated query payload directly. Column sort cycles through ascending,
descending, and unsorted states; filtering searches every visible column.

<CodeExample
  filename="components/query-rows.tsx"
  code={`import { DataTable } from "@/components/tessera-agent/data-table"

export function QueryRows({ artifact }) {
  return (
    <DataTable
      artifact={artifact}
      pageSize={20}
      searchable={artifact.rowCount > 20}
    />
  )
}`}
/>

## API Reference

<ApiReference
  name="DataTable"
  properties={[
    { name: "artifact", type: "QueryResultSurface", required: true, description: "Validated columns and rows used for structure, formatting, and stable keys." },
    { name: "locale", type: "string", defaultValue: '"en-US"', description: "Locale used for values, row counts, and text comparison." },
    { name: "pageSize", type: "number", defaultValue: "10", description: "Maximum number of rows rendered on one page." },
    { name: "searchable", type: "boolean", defaultValue: "true", description: "Displays the local row filter when enabled." },
  ]}
/>

Data Table emits no agent actions. It only changes local inspection state.
