Catalog 只有一个公开 Component Contract：`data.chart`。它通过 `spec.recipe` Discriminant
选择 17 种完整分析设计之一：

1. Steps Bars
2. Pipeline Stage Bars
3. Sleep Score
4. Revenue per Account Scatter
5. Tracked Time Sankey
6. Visitors Radial
7. Visitors Radar
8. Activity Calendar
9. Revenue Smooth Area
10. Active Users Heatmap
11. Sign-up Funnel
12. Earned so Far Bars
13. Contributions Heatmap
14. Sessions + Conversion Combo
15. Devices Bars
16. Visitors Stacked Area
17. Activity Rings

Recipe 定义的是信息结构，不是任意视觉参数。Authoring Spec 只保存 Typed Resource Binding；
Row 由 Host 解析，并且只在 Node-scoped Render Projection 中校验。Recipe 不能包含原始颜色、
CSS、Callback、React Props 或 SVG Markup。

视觉主题由 Host 通过 `.og-ui` 上的 `--og-*` CSS 属性控制。颜色角色、图表强调色、阴影和完整
圆角体系都能在不修改 ChartSpec 的情况下覆盖。`--og-radius-base` 会调整整套圆角比例，
`--og-radius-panel`、`--og-radius-card` 等语义 Token 也可以单独覆盖。

下面每个预览都从官方 Authoring Fixture 开始，通过 Resource Gateway 发布数据集，再经过真实的
`SurfaceController`、`GenerativeSurface` 与 Verified Renderer Registry 解析。组件目录不使用
仅为文档制作的仿制实现。
