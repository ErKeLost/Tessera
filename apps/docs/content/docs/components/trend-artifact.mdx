---
title: Trend Artifact
description: Focus attention on one time-series metric, its change, target, and an evidence-backed interpretation.
---

Use Trend Artifact when the answer is the movement of one metric over time—not
an arbitrary chart builder. It keeps the latest value and period change visible
while preserving exact point selection for a follow-up agent action.

## Usage

Supply ordered ISO timestamps and numeric values. The renderer calculates the
period change when `change` is omitted and formats all visible numbers locally.

<CodeExample
  filename="components/activation-trend.tsx"
  code={`"use client"

import { TesseraPreviewProvider } from "@/components/tessera-agent/bridge"
import { TrendArtifact } from "@/components/tessera-agent/trend-artifact"

export function ActivationTrend({ artifact }) {
  return (
    <TesseraPreviewProvider onAction={(event) => inspectPoint(event.payload)}>
      <TrendArtifact artifact={artifact} locale="en-US" />
    </TesseraPreviewProvider>
  )
}`}
/>
