---
title: Mastra
description: 使用一个 Processor 和一个 Renderer，把 Open Generative 接入最新 Mastra 1.61 Agent。
---

`@open-generative/mastra` 只面向当前 Mastra 1.61 Processor API。应用不需要编译组件
Schema、维护 UI Prompt、为每个组件注册 Tool，也不管理 Proposal Transaction。

## 服务端

创建一个 Host，并向现有 Agent 添加一个 Processor。Domain Tool 尚未产生可渲染 Resource 时，
`resolve` 返回 `undefined`；Resource 就绪后，Processor 自动生成并注入本轮唯一的
`present_ui` Tool。

```ts
import { Agent } from "@mastra/core/agent";
import { createOpenGenerativeHost } from "@open-generative/host";
import {
  MASTRA_PRESENT_UI_TRACING_OPTIONS,
  createOpenGenerativeMastraProcessor,
} from "@open-generative/mastra";

const host = await createOpenGenerativeHost();
const openGenerative = createOpenGenerativeMastraProcessor({
  resolve: async () => host.prepareTurn({
    authority,
    resources: currentResources(),
    presentationPolicy: "auto",
  }),
});

const agent = new Agent({
  id: "data-agent",
  name: "Data Agent",
  model,
  tools: domainTools,
  inputProcessors: [openGenerative],
});

const stream = await agent.stream(messages, {
  tracingOptions: MASTRA_PRESENT_UI_TRACING_OPTIONS,
});
```

Agent Streaming 时，Processor 通过 Mastra 自带的 Processor Writer 写入已经 Commit 的
`data-openGenerativeSurface` Part，并在 Commit 后移除 `present_ui`。应用不需要 Drain 或转换
Surface Event。

Processor 会把第一个可用 Host Turn 缓存在 Mastra 的 Request-scoped Processor State 中。
`resolve` 可以直接调用 `host.prepareTurn()`；应用不需要维护 Per-step Turn Cache。

启用 Mastra Tracing 时必须使用上面的 Tracing Options。Mastra 会在 Display/Transcript
Transform 前创建 Tool-call Span；这两个选项阻止 Proposal Payload 进入 Trace Input/Output。

## 客户端

使用 Package 自己的 Renderer 渲染 Data Part：

```tsx
import { OpenGenerativeRenderer } from "@open-generative/ui";
import "@open-generative/ui/styles.css";

<OpenGenerativeRenderer event={part.data} />
```

Renderer 内部拥有已验证的 Contract Registry、`SurfaceController`、官方 Renderer Registry、
Replay、Cleanup、Loading State 与 Command Bridge。只有 Surface 暴露交互时，Host 才需要传入
`onCommand`。

```text
domain tool -> Resource -> Mastra Processor -> present_ui -> committed data part
-> OpenGenerativeRenderer
```

底层 Tool/Session Constructor 仍供自定义 Host 使用，但不属于普通应用接入路径。
