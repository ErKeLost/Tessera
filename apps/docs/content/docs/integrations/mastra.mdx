title: Mastra
description: Use the implemented server-only Mastra 1.61 present_ui adapter in Tessera Agent.
---

`@open-generative/mastra` is the implemented server-only adapter for Mastra
1.61. It calls Mastra's real `createTool()` API and turns compiler output into a
request-scoped `present_ui` tool without creating another protocol, compiler,
runtime, or renderer.

## Create the turn adapter

`createMastraIncrementalPresentUi()` returns the values that must stay together
for the turn: the compiler system prompt, the exact compiled contract,
`tools.present_ui`, and the mandatory tracing options. Its three Mastra 1.61
input hooks feed complete operation frames into the same incremental compiler
session that `execute` finalizes.

```ts
import {
  compilePresentUi,
  createIncrementalPresentUiCompilerSession,
} from "@open-generative/compiler";
import { createMastraIncrementalPresentUi } from "@open-generative/mastra";
import { Agent } from "@mastra/core/agent";

const compiled = compilePresentUi({ catalog: turnCatalog });
const presentUi = createMastraIncrementalPresentUi({
  compiled,
  maxAttempts: 3,
  createSession: ({ toolCallId, abortSignal }) =>
    createIncrementalPresentUiCompilerSession({
      compiled,
      turn: createTurnForRequest({ toolCallId, abortSignal }),
    }),
});

const agent = new Agent({
  id: "tessera-data-agent",
  name: "Tessera Data Agent",
  model,
  instructions: presentUi.system,
  tools: { ...domainTools, ...presentUi.tools },
});

// Use one execution mode per request. Both must carry the tracing gate.
const result = await agent.generate(messages, {
  tracingOptions: presentUi.tracingOptions,
});
const stream = await agent.stream(messages, {
  tracingOptions: presentUi.tracingOptions,
});
```

`createTurnForRequest()` above is the Tessera Host composition helper that
constructs the official `ProposalCompilerTurn` with the request's frozen
Catalog slice, authority, transaction, and runtime. Use
`createMastraIncrementalPresentUiTool()` when the application only needs the
Tool instance; tool-only hosts must import and pass
`MASTRA_PRESENT_UI_TRACING_OPTIONS` themselves. The adapter validates complete
input against the compiler's canonical schema before finalization. Invalid input throws
`MastraPresentUiInputError` with the stable code
`mastra.present-ui-input-invalid`.

## Bounded model and transcript output

The adapter installs `toModelOutput`, display transforms, and transcript
transforms on the Mastra Tool. Raw proposal input, input deltas, execution
output, and validation errors are replaced with bounded summaries. Domain data
tools stay separate; query rows remain in the server-side Resource Gateway.

Mastra creates tool-call observability spans before per-tool display and
transcript transforms run. For that reason, those transforms cannot protect
trace input or output by themselves. Every `agent.generate()` or
`agent.stream()` call that installs this tool must pass
`tracingOptions: presentUi.tracingOptions`; the adapter fixes both
`hideInput` and `hideOutput` to `true`. When combining other trace settings,
spread them first so these two required flags cannot be overridden:

```ts
const result = await agent.generate(messages, {
  tracingOptions: {
    ...otherTracingOptions,
    ...presentUi.tracingOptions,
  },
});
```

The executor is still the host integration point. It must use the same frozen
Catalog slice as `compiled`, commit through the canonical compiler/Host path,
and publish only committed `SurfaceEventEnvelope` values. Mastra cannot expand
the turn's Contract slice, resource grants, or authority.

```text
Mastra 1.61 Agent or Workflow
-> validated present_ui proposal
-> shared compiler + Host commit
-> trusted SurfaceEventStream
-> SurfaceController
-> GenerativeSurface
-> RendererRegistry
```

The package has no browser export and no `ArtifactPart` or `ArtifactRenderer`
compatibility layer.
