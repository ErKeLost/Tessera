Tessera Agent 的官方 React Renderer 基于 shadcn/ui Primitive 与 Recharts 构建，
但当前没有公开的 `tessera-agent` CLI，也没有远程 `tessera-agent.dev` Registry。
在 Data Agent 成功证明完成之前，Renderer 源码继续留在本仓库。

## 当前源码

`@open-generative/ui` 是本地 React 实现 Package。这个名字标记未来抽离边界；
当前组件和组件文档仍然属于 Tessera Agent 成功证明。

Package 导出精确的 `data.chart` Node Renderer、官方 Registry Factory、共享 UI Primitive 与样式表：

```tsx
import { GenerativeSurface } from "@open-generative/react";
import { createOfficialRendererRegistry } from "@open-generative/ui";
import "@open-generative/ui/styles.css";
```

完整应用挂载还需要 `SurfaceController`。唯一支持的渲染链是：

```text
SurfaceEventStream -> SurfaceController -> GenerativeSurface -> RendererRegistry
```

这里没有 `ArtifactRenderer` 兼容 Facade，也没有按 Artifact 分叉的渲染路径。

## 本地验证

在仓库根目录执行：

```bash
bun install
bun --cwd packages/components test
bun --cwd packages/ui typecheck
bun --cwd packages/ui test
bun --cwd packages/ui build
```

Contract 定义来自 `@open-generative/components`，React Renderer Registration 来自
`@open-generative/ui`。测试必须证明精确 Contract Identity、Resolved Props Validation、
Browser Safety、Accessibility 与全部 17 个 Chart Recipe Fixture。

## 未来源码分发

后续可以通过 shadcn Registry 分发可编辑 Renderer 源码，但只有 Registry URL、生成 Manifest、
依赖闭包、Clean-host 安装测试、版本固定与 Integrity Check 全部存在后，文档才能把它写成可用能力。
未来 Registry 只改变分发方式，不能分叉 Component Contract，也不能创建第二套 Renderer 架构。
