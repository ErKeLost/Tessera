---
title: 分析视图源码
description: Tessera 如何拥有基于 shadcn/ui 的分析视图，同时不发布组件 Registry。
---

Tessera Studio 的分析视图由本仓库中的本地 shadcn/ui Primitive 与图表实现组成，并随 Studio 一起提供。

当前没有公开组件 Package、shadcn Registry URL、组件 CLI 或复制安装路径。用户安装 Tessera Studio
后，会直接获得 Agent 使用的 Renderer。

源码仍然采用 Contract 驱动，因此 Tessera 可以在渲染前校验每一个生成视图。当前 Gallery 覆盖
全部 17 个图表 Recipe，并使用与 Studio 相同的 Renderer；它是产品文档，不是分发 Registry。

请查看[分析视图目录](/docs/components/generative-ui-catalog)。
