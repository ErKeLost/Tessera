---
title: Analysis View Source
description: How Tessera owns its shadcn/ui-based analysis views without publishing a component registry.
---

Tessera Studio's analysis views are built from local shadcn/ui primitives and
the chart implementation in this repository. They ship as part of Studio.

There is no public component package, shadcn registry URL, component CLI, or
copy-paste installation path. Users install Tessera Studio and receive the
renderer used by the Agent automatically.

The source remains contract-driven so Tessera can validate every generated
view before rendering it. The current gallery covers all 17 supported chart
recipes and uses the same renderer as Studio; it is product documentation, not
a distribution registry.

See the [analysis view catalog](/docs/components/generative-ui-catalog).
