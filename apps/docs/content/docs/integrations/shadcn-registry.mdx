title: shadcn/ui Components
description: How Tessera Agent owns and validates its current Generative UI renderer source.
---

Tessera Agent's official React renderers are built from shadcn/ui primitives and
Recharts, but there is currently no public `tessera-agent` CLI and no remote
`tessera-agent.dev` registry. The renderer source remains in this repository
until the data-agent proof succeeds.

## Current source

`@open-generative/ui` is the local React implementation package. Its name marks
the future extraction boundary; the components and their documentation are
currently part of the Tessera Agent proof.

The package exports the 12 exact node renderers, official registry factories,
shared UI primitives, and a stylesheet:

```tsx
import { GenerativeSurface } from "@open-generative/react";
import { createOfficialRendererRegistry } from "@open-generative/ui";
import "@open-generative/ui/styles.css";
```

The complete application mount also needs a `SurfaceController`. The only
supported rendering chain is:

```text
SurfaceEventStream -> SurfaceController -> GenerativeSurface -> RendererRegistry
```

There is no `ArtifactRenderer` compatibility facade and no per-artifact render
path.

## Local verification

From the repository root:

```bash
bun install
bun --cwd packages/components test
bun --cwd packages/ui typecheck
bun --cwd packages/ui test
bun --cwd packages/ui build
```

Contract definitions come from `@open-generative/components`; React renderer
registrations come from `@open-generative/ui`. Tests must prove exact Contract
identity, resolved-props validation, event-port parity, browser safety, full
state fixtures, accessibility, and chart recipe coverage.

## Future source distribution

A shadcn registry may later distribute editable renderer source. It cannot be
documented as available until the registry URL, generated manifests, dependency
closure, clean-host installation tests, version pinning, and integrity checks
all exist. A future registry changes distribution only; it cannot fork the
Component Contracts or create a second renderer architecture.
