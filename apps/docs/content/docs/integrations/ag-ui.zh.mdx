title: AG-UI 状态
description: AG-UI 不属于 Tessera Agent 当前 Runtime 或公开接入面。
---

Tessera Agent 当前没有对外提供 AG-UI 集成。Studio 使用 Mastra 运行 Agent，并使用 AI SDK UI
Message Stream 连接 Nitro Server 与 React Client。

保留本页是为了让旧链接不再指向已经不符合产品现状的安装说明。Tessera 用户目前没有可安装的
AG-UI Package、Custom Event Contract 或额外配置步骤。

当前已经实现并测试的运行时请查看 [Mastra Runtime](./mastra)与 [AI SDK Transport](./ai-sdk)。
