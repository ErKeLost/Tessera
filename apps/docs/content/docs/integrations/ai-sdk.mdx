---
title: AI SDK
description: Add Open Generative to AI SDK 7.0.77 with one dynamic adapter and one Renderer.
---

`@open-generative/ai-sdk` targets AI SDK 7.0.77 and later v7 patches. It does
not include an AI SDK v6 compatibility path.

## Server

The high-level adapter returns the existing `tools + prepareStep` pair expected
by AI SDK v7. `resolve` returns a Host Turn, not another UI adapter. Tool schema,
prompt generation, incremental input, repair, and commit remain package-owned.

```ts
import {
  createUIMessageStream,
  createUIMessageStreamResponse,
  streamText,
} from "ai";
import { createOpenGenerativeHost } from "@open-generative/host";
import { createOpenGenerativeAISdkAdapter } from "@open-generative/ai-sdk/server";

const host = await createOpenGenerativeHost();

const stream = createUIMessageStream({
  async execute({ writer }) {
    const openGenerative = createOpenGenerativeAISdkAdapter({
      tools: domainTools,
      writer,
      resolve: async () => host.prepareTurn({
        authority,
        resources: currentResources(),
        presentationPolicy: "auto",
      }),
    });

    const result = streamText({ model, messages, ...openGenerative });
    writer.merge(result.toUIMessageStream());
  },
});

return createUIMessageStreamResponse({ stream });
```

Before resources exist, only the domain tools are active. On the next AI SDK
step, the adapter activates `present_ui` and injects the Contract-generated
instructions. After commit it writes the verified Surface data part and removes
the tool.

The adapter caches the first available Host Turn for that `streamText` call, so
`resolve` may call `host.prepareTurn()` directly without application lifecycle
state.

For non-UI server work, omit `writer` and call `openGenerative.drainEvents()`.

## Client

```tsx
import { OpenGenerativeRenderer } from "@open-generative/ui";
import "@open-generative/ui/styles.css";

<OpenGenerativeRenderer event={part.data} />
```

Use `isOpenGenerativeSurfaceDataPart()` when routing mixed AI SDK parts. The
canonical render path remains one chain:

```text
AI SDK v7 -> verified Surface data part -> OpenGenerativeRenderer
```

Low-level tool constructors remain available for custom Hosts; ordinary users
do not compile or maintain a component prompt.
