---
title: AI SDK
description: Use the implemented AI SDK v7 proposal and trusted Surface-event adapters in Tessera Agent.
---

Tessera Agent integrates AI SDK v7 through `@open-generative/ai-sdk`. The
package is transport glue around the canonical Generative UI pipeline; it does
not own Component Contracts, proposal commits, authority, resources, or React
rendering.

The package root exports only wire constants and types. Server and browser code
must use the explicit `./server` and `./client` entry points so their dependency
closures remain separate.

## Present the model tool

`createPresentUiTool()` creates a real AI SDK v7 tool from the compiler output.
It validates tool input against the frozen turn schema before calling the
application-supplied executor. Its `toModelOutput` transform returns a bounded
acknowledgement, so proposal payloads and query rows do not re-enter model
context.

```ts
import { compilePresentUi } from "@open-generative/compiler";
import { createPresentUiTool } from "@open-generative/ai-sdk/server";
import { streamText } from "ai";

const compiled = compilePresentUi({ catalog: turnCatalog });
const presentUi = createPresentUiTool({
  compiled,
  execute: acceptPresentUiProposal,
});

const result = streamText({
  model,
  system: compiled.systemPrompt,
  messages,
  tools: { ...domainTools, present_ui: presentUi },
});
```

`turnCatalog` must be the same frozen, task-scoped Catalog slice used by
`acceptPresentUiProposal`. That executor connects validated authoring input to
the shared compiler and Host commit path; it must not publish model tool input
directly as a trusted event.

## Stream committed Surface events

Only hash-verified `SurfaceEventEnvelope` values can enter the AI SDK data-part
stream. The adapter uses the transient `data-openGenerativeSurface` part and
keeps the canonical event unchanged inside `data`.

```ts
import { createOpenGenerativeUIMessageStream } from "@open-generative/ai-sdk/server";
import { createUIMessageStreamResponse } from "ai";

const stream = createOpenGenerativeUIMessageStream(surfaceEvents);
return createUIMessageStreamResponse({ stream });
```

Use `toOpenGenerativeSurfaceDataChunk(event)` when composing the event into an
existing AI SDK UI message stream yourself.

## Consume in the browser

The client adapter recognizes the package-owned data part, parses and verifies
the event payload, then delegates it to the existing `SurfaceController`.

```ts
import { consumeOpenGenerativeSurfaceDataPart } from "@open-generative/ai-sdk/client";

for (const part of message.parts) {
  await consumeOpenGenerativeSurfaceDataPart(surfaceController, part);
}
```

For routing without consumption, use
`isOpenGenerativeSurfaceDataPart()` and
`decodeOpenGenerativeSurfaceDataPart()`.

The resulting render path remains exactly:

```text
AI SDK v7 data part
-> verified SurfaceEventEnvelope
-> SurfaceController
-> GenerativeSurface
-> RendererRegistry
```

There is no `ArtifactPart`, `ArtifactRenderer`, or legacy compatibility path.
