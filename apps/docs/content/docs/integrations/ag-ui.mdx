---
title: AG-UI Status
description: AG-UI is not part of the current Tessera Agent runtime or public integration surface.
---

Tessera Agent does not currently expose an AG-UI integration. Studio uses
Mastra for the Agent runtime and AI SDK UI Message Stream for its Nitro-to-React
transport.

This page is retained so older links do not point to an installation guide that
no longer represents the product. There is no supported AG-UI package, custom
event contract, or setup step for Tessera users.

See [Mastra runtime](./mastra) and [AI SDK transport](./ai-sdk) for the runtime
that is implemented and tested today.
