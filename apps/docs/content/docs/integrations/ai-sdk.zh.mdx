---
title: AI SDK
description: 在 Tessera Agent 中使用已经实现的 AI SDK v7 Proposal 与可信 Surface Event Adapter。
---

Tessera Agent 通过 `@open-generative/ai-sdk` 接入 AI SDK v7。这个 Package 只负责把 Framework
Transport 接到 Canonical Generative UI Pipeline；Component Contract、Proposal Commit、权限、
Resource 与 React Renderer 仍由各自的 Canonical Package 负责。

Package Root 只导出 Wire Constant 与 Type。服务端与浏览器必须分别使用显式的 `./server` 和
`./client` Entry，确保两侧依赖闭包保持隔离。

## 创建模型 Tool

`createPresentUiTool()` 使用 Compiler Output 创建真正的 AI SDK v7 Tool。它先按照本轮冻结的
Schema 校验 Tool Input，再调用应用提供的 Executor。`toModelOutput` 只向模型返回受限确认信息，
原始 Proposal Payload 和 Query Row 不会重新进入 Model Context。

```ts
import { compilePresentUi } from "@open-generative/compiler";
import { createPresentUiTool } from "@open-generative/ai-sdk/server";
import { streamText } from "ai";

const compiled = compilePresentUi({ catalog: turnCatalog });
const presentUi = createPresentUiTool({
  compiled,
  execute: acceptPresentUiProposal,
});

const result = streamText({
  model,
  system: compiled.systemPrompt,
  messages,
  tools: { ...domainTools, present_ui: presentUi },
});
```

`turnCatalog` 必须与 `acceptPresentUiProposal` 使用同一份按任务裁剪并冻结的 Catalog Slice。
Executor 负责把已验证 Authoring Input 接到共享 Compiler 与 Host Commit Path；不能把模型 Tool
Input 直接发布成可信 Event。

## 传输已提交 Surface Event

只有 Hash 验证成功的 `SurfaceEventEnvelope` 才能进入 AI SDK Data Part Stream。Adapter 使用
Transient `data-openGenerativeSurface` Part，Canonical Event 保持原样放在 `data` 中。

```ts
import { createOpenGenerativeUIMessageStream } from "@open-generative/ai-sdk/server";
import { createUIMessageStreamResponse } from "ai";

const stream = createOpenGenerativeUIMessageStream(surfaceEvents);
return createUIMessageStreamResponse({ stream });
```

需要把 Event 合并到应用自己的 AI SDK UI Message Stream 时，使用
`toOpenGenerativeSurfaceDataChunk(event)`。

## 浏览器消费

Client Adapter 先识别 Package 专属 Data Part，再 Parse 并验证 Event Payload，最后交给现有
`SurfaceController`。

```ts
import { consumeOpenGenerativeSurfaceDataPart } from "@open-generative/ai-sdk/client";

for (const part of message.parts) {
  await consumeOpenGenerativeSurfaceDataPart(surfaceController, part);
}
```

只需要分流或解码时，使用 `isOpenGenerativeSurfaceDataPart()` 与
`decodeOpenGenerativeSurfaceDataPart()`。

最终渲染路径仍然只有一条：

```text
AI SDK v7 data part
-> verified SurfaceEventEnvelope
-> SurfaceController
-> GenerativeSurface
-> RendererRegistry
```

这里没有 `ArtifactPart`、`ArtifactRenderer` 或旧兼容路径。
