本站只描述一个产品：**Tessera Agent**。当前仓库是它完整的 Generative UI 架构与成功证明场地：
Protocol、Compiler、Runtime、权限边界、Client Controller、React Surface、数据组件、Fixture 与
Evaluation Gate 都先在这里完整实现，直到 data-agent 体验通过端到端验证。

framework-neutral Package 使用 `@open-generative/*` namespace，是为了提前固定未来的抽取边界。
它在当前仓库中不是第二个产品，也不会改变当前验收对象。只有 Tessera Agent 通过全部 proof gate 后，
才会创建独立的 Open Generative 项目。

## 唯一渲染链路

```text
trusted SurfaceEventStream
-> SurfaceController
-> GenerativeSurface
-> exact RendererRegistry
```

模型只提出声明式 Node，不生成 JSX、HTML、CSS、SQL、Tool 名称、Credential 或可执行公式。
数据、身份、校验、权限、状态、Effect、持久化、Commit 与渲染全部由 Host 掌控。

## 当前范围

底层不是 MVP，而是直接实现终局架构；初始 Catalog 则有意保持克制：12 个正交 Component Contract、
70 个基于 shadcn/Recharts 的 Chart 与 Tooltip Recipe，以及 data-agent 专属 Fixture。Trend、Funnel、
Cohort、Anomaly、Forecast 等体验由这些 Contract 组合完成，不再成为协议级固定大组件。
