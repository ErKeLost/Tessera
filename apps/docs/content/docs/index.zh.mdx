Tessera Agent 面向需要检查、复现和继续行动的数据库团队。它先发现已连接的
Catalog，再基于可见 Relation 规划，执行有上限的读取，并为结果保留 Evidence。

本站只描述 **Agent 产品**：如何连接数据库、定义 Tool 契约、理解运行流程、处理写操作的
审批边界，以及使用 Studio 内置的生成式分析视图。

## 一次请求的生命周期

```text
问题
  -> Catalog 范围
  -> 语义计划
  -> 有上限的读取
  -> Evidence + Diagnostic
  -> 回答或审批后的写操作
```

模型不会拿到连接密钥，也不会获得无限制的数据库表面。Catalog 快照、权限决策、
Connector 执行、具体错误和最终结果都由 Tessera 掌控。
