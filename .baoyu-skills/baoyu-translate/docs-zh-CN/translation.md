# Artifact Agent Chinese documentation translation

The final translations are integrated directly as Fumadocs locale files under
`apps/docs/content/docs` using the `.zh.mdx` and `meta.zh.json` naming scheme.

Translated sections:

- Introduction and examples
- Component catalog overview
- Core concepts
- AI SDK, Mastra, and shadcn Registry integrations
- Data analyst agent architecture, run loop, SQL safety, provenance, and evaluation

Component reference pages without a dedicated `.zh.mdx` file intentionally use
Fumadocs English fallback until their API prose is translated.
