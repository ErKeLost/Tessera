# Translation analysis

- Domain: data-agent architecture, declarative UI protocols, React component documentation.
- Audience: developers and technical researchers.
- Tone: concise, academic technical documentation.
- Preserve verbatim: package names, component names, type names, field names, commands, code blocks, URLs, and product name `Artifact Agent`.
- Translate consistently: AI Agent -> AI 智能体; guardrails -> 护栏; provenance -> 溯源; grounding -> 证据支撑; renderer -> 渲染器; payload -> 载荷; run controller -> 运行控制器.
- Keep `Artifact` in English when it names the protocol object or component family; use Chinese explanation around it where needed.
- Do not add translator notes inside product documentation.
